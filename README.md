# Rock, Paper, Scissors Game (C++)

A classic interactive command-line **Rock, Paper, Scissors** game written in C++ for Windows. Play multiple rounds against the computer, view round-by-round results with visual feedback, and track your overall game statistics.

---

# 🎮 How to Play

### Step 1: Set Game Rounds
When launched, enter a number between `1` and `10` to define the total length of your match.

### Step 2: Make Your Move
Input your choice key when prompted for each round: 🪨 **Rock** | 📄 **Paper** | ✂️ **Scissors**

### Step 3: View Round Outcome
The outcome displays immediately alongside visual and auditory cues:
* 🟩 **Green Screen:** Round won by **Player**.
* 🟥 **Red Screen + Audio Beep:** Round won by **Computer**.
* ⬛ **Black Screen:** Round ended in a **Draw**.

### Step 4: Endgame Summary
Once all rounds finish, the console displays a complete match summary detailing:
* **Total Rounds Played**
* **Player 1 Total Wins**
* **Computer Total Wins**
* **Total Draws**
* **Final Game Winner**

### Step 5: Play Again or Exit
* Enter `1` to **Restart** a fresh game session.
* Enter `2` to **Exit** the program.
